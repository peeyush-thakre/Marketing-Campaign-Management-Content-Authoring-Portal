# Marketing Operations Portal

A responsive **Marketing Operations and Content Authoring Portal** built using **HTML5, CSS3, JavaScript, and jQuery**.

The project simulates a marketing team's workflow for managing campaigns, website content, and campaign performance through an interactive web interface.

## 🎯 Project Overview

The portal provides a centralized interface where marketing users can:

- Manage marketing campaigns
- Create and edit website content
- Publish and unpublish content
- Search and filter campaign records
- Monitor campaign KPIs and performance
- Store data using browser LocalStorage

The project is completely frontend-based and does not require a backend or database.

## ✨ Key Features

### 📊 Marketing Dashboard

- Create campaigns

### 📝 Content Authoring
- Create website content
- Edit content

### 🔎 Interactive Functionality
- Dynamic search and filtering

### 💾 Data Persistence

Campaign and content data are stored using **LocalStorage**, allowing data to remain available after refreshing the browser.
